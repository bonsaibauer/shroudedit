## Unsupported Project

%R5.8%, ShroudEdit does not support uploading multiple variations of your project as separate versions. \
New Versions of your project should strictly be a linear upgrade of the same content. \
Having alternate versions of your content on the same project will hurt the functionality of supported launchers such as ShroudForge, preventing users from updating your content and making it harder for users to find the version they want. \
To ensure a smooth experience for you and your users, please upload each alternate version of your modpack as its own Modpack project, thank you.
