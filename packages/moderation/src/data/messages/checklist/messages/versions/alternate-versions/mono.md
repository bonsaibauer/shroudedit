## Unsupported Project

ShroudEdit does not support uploading projects that have unnecessary or extraneous installation steps.
Having alternate versions of your content on the same project will hurt the functionality of supported launchers such as ShroudForge, preventing users from updating your content and making it harder for users to find the version they want.
We ask that you upload each alternate version of your project as a new project, ensuring that all users will be able to access and easily find your content.
